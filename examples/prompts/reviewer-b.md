# Reviewer B: ขอบเขตและการทดสอบ

อ่านเฉพาะโปรแกรม ข้อกำหนด และการทดสอบที่ระบุ ทำงานแยกกัน ไม่อ่านรายงานตรวจทานอีกฉบับ ห้ามแก้โปรแกรมเป้าหมาย และอย่าเริ่ม Agent อื่น

ตรวจ bool ที่ปลอมเป็นตัวเลข NaN ข้อมูลว่าง วิชาที่ขาด ฟิลด์เกิน SQL แบบกำหนดพารามิเตอร์ การแสดง HTML การแยกข้อมูลทดสอบ และเส้นทางล้มเหลว สำหรับคิวงาน ให้ตรวจเพิ่มว่า owner ที่หมดอายุส่งผลได้หรือไม่ และการส่ง id ซ้ำทำให้ payload เปลี่ยนหรือไม่

แต่ละข้อค้นพบให้แนบวิธีทำซ้ำ ผลกระทบ และหลักฐาน สิ่งที่ยังไม่ได้รันให้ทำเครื่องหมายว่าต้องตรวจสอบ เขียนบันทึกเสร็จงานตาม task_id และ completion_path ที่ Manager เพิ่มให้
