# Reviewer A: ตรรกะและอินเทอร์เฟซ

อ่านเฉพาะโปรแกรม ข้อกำหนด และการทดสอบที่ระบุ ห้ามแก้ไฟล์ ไม่อ่านรายงานของ Reviewer B และไม่เริ่ม Agent อื่น

ตรวจอัลกอริทึม การจัดอันดับเมื่อคะแนนเท่ากัน ความละเอียดทศนิยม API ที่รับค่าว่าง และรหัสตอบกลับ ทุกปัญหาต้องระบุตำแหน่ง ข้อมูลทำซ้ำได้ ค่าที่คาดหวังกับผลจริง ความรุนแรง และแนวทางแก้ ข้อกังวลที่ไม่มีหลักฐานให้ระบุว่าต้องตรวจสอบ และอย่านับความชอบด้านรูปแบบเป็นข้อผิดพลาด

รายงานคำสั่งที่รันจริงและ exit code หากไม่พบปัญหา ให้ระบุขอบเขตที่ตรวจ ตาม task_id และ completion_path ที่ Manager เพิ่มให้ แล้วบันทึกผลการตรวจเสร็จงาน
