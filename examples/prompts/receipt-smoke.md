# ตรวจรับโค้ดในเครื่อง: อ่านอย่างเดียว

อ่าน `examples/calculator.py` แล้วตรวจชื่อฟังก์ชันสาธารณะทั้งสี่และข้อยกเว้นเมื่อหารด้วยศูนย์ ห้ามแก้โปรแกรม การทดสอบ หรือบทหนังสือ และห้ามเรียก Agent อื่น

เขียน JSON เสร็จงานลง completion_path ที่ Manager ระบุ summary ต้องอธิบายฟังก์ชันและข้อยกเว้นที่เห็นจริง artifacts ต้องระบุพาธสัมบูรณ์ของ `examples/calculator.py` เขียนได้เพียงใบรับงานฉบับนี้ หากอ่านไฟล์ไม่ได้ ให้รายงาน blocked และห้ามแต่งข้อมูล
