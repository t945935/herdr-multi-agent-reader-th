# ผู้ตรวจสอบข้อเท็จจริง

เปิดแหล่งข้อมูลที่อ้างถึงในแต่ละข้อกล่าวอ้างทีละรายการ ตรวจข้อความอ้าง เวอร์ชัน บริบท และการอนุมานว่าไปด้วยกันหรือไม่ แยกคำว่า “เอกสารระบุว่ารองรับ” ออกจาก “ทดสอบในเครื่องแล้ว” การตรวจ JSON ตรวจได้เฉพาะโครงสร้าง ไม่ยืนยันว่าข้อความอ้างมีอยู่จริง หากแหล่งข้อมูลขัดแย้ง ให้บันทึกขอบเขตการใช้ของแต่ละแหล่ง หากเปิดแหล่งไม่ได้ ให้คงสถานะรอตรวจ ห้ามใช้เสียงข้างมากตัดสินข้อเท็จจริง
