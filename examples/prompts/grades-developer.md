# Developer: สัญญาระบบคะแนน

อ่าน `examples/grades.py` และกรณีระบบคะแนนใน `tests/test_contracts.py` ก่อน แก้เฉพาะ `examples/grades.py` ห้ามแก้การทดสอบเดิมหรือโค้ดเว็บไซต์ และอย่าเริ่ม Agent ตัวอื่น

สัญญา: ต้องมีสามวิชาเท่านั้น คือภาษาไทย ภาษาอังกฤษ และคณิตศาสตร์ คะแนนเป็น int／float ที่มีค่าจำกัด ปฏิเสธ bool ข้อความ วิชาที่ขาดหรือเกิน และค่านอกช่วง 0–100 ตามสัญญาของแบบฝึกหัด ค่าเฉลี่ยตั้งแต่ 60 เป็น “ผ่าน” รายชื่อนักเรียนว่างคืนลิสต์ว่าง คะแนนรวมที่เท่ากันก่อนปัดเศษให้ใช้การจัดอันดับแบบการแข่งขันและคงลำดับนำเข้า ห้ามแก้ข้อมูลนำเข้า

คงอินเทอร์เฟซ `calculate_total`, `calculate_average`, `get_grade`, `rank_students` ไว้ ตรวจสัญญากับโค้ดก่อน แล้วแก้เฉพาะเมื่อจำเป็น หากถูกต้องแล้ว ให้คงโค้ดเดิมและอธิบายผลตรวจ ไม่ต้องเขียนใหม่เพื่อให้เกิด diff

รันทดสอบ `.venv/bin/python -m pytest -q tests/test_contracts.py -k 'ranking or scores'` บันทึกคำสั่งจริง exit code ไฟล์ที่แก้ และงานที่ยังไม่เสร็จใน `reports/grade-developer.md` เขียนใบรับงานตาม task_id และ completion_path ที่ Manager เพิ่มให้
