# QA: ระบบคะแนน

อ่านอินเทอร์เฟซของ `examples/grades.py` และกรณีคะแนนเดิมใน `tests/test_contracts.py` ตรวจสัญญาระบบคะแนนอย่างเป็นอิสระ ห้ามแก้โปรแกรม ห้ามลบการทดสอบเดิม ห้ามอ่านการประเมินตนเองของ Developer และห้ามเริ่ม Agent อื่น

เพิ่มหรือแก้ได้เฉพาะ `tests/test_grades_review.py` และบันทึกรายงานใน `reports/grade-qa.md` ตรวจชุดวิชาสามวิชา ขอบเขต 0／100／60 bool／NaN／ข้อความ ข้อมูลว่าง ชื่อนักเรียน อันดับเสมอ 1／1／3 ความละเอียดก่อนปัดเศษ และการไม่แก้ข้อมูลนำเข้า

ใช้ pytest หากการทดสอบเดิมครอบคลุมกรณีใดพอแล้ว ให้อธิบายเกณฑ์ก่อนเพิ่มเฉพาะกรณีที่ยังมีประโยชน์ อย่าทำสำเนาการทดสอบเดิม และอย่าทดสอบ FastAPI, SQLite หรือ CRUD ของเว็บไซต์ เพราะไม่ใช่งานระบบคะแนน

รันการทดสอบจริงและเก็บคำสั่ง exit code ข้อค้นพบ และสิ่งที่ยังไม่ได้รัน เขียนใบรับงานตาม task_id และ completion_path ที่ Manager เพิ่มให้ ใน artifacts ให้ระบุรายงานและไฟล์ทดสอบที่ตนสร้าง
