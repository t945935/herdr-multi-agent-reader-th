# รายการตัวอย่าง

รันคำสั่งทั้งหมดจากรากแพ็กเกจตัวอย่าง ใช้ `examples.*` สำหรับการ import ใน Python

| บท | จุดเริ่มต้น | การตรวจรับ |
|---|---|---|
| เครื่องคิดเลข | `calculator.py` | สี่การคำนวณ การหารด้วยศูนย์ และชนิดข้อมูล |
| ระบบคะแนน | `grades.py` | ขอบเขตคะแนน วิชาที่ขาด และอันดับเสมอแบบ 1,1,3 |
| ส่งต่องาน | `handoff.py`, `../scripts/make_handoff.py` | การมีไฟล์ ขอบเขตโปรเจกต์ และ SHA-256 |
| เว็บไซต์จัดการงาน | `task_manager/` | CRUD การตรวจข้อมูล หน้าเว็บ และการคงอยู่หลังเริ่มใหม่ |
| วิจัยเทคนิค | `research.py` | ข้อกล่าวอ้าง แหล่งข้อมูล คำอ้างอิง และสิ่งที่ยังไม่แน่ใจ |
| สายงานพัฒนา | `pipeline.py` | exit code, timeout, ตรวจผลงาน และหยุดเมื่อผิดพลาด |
| คิวงานกู้คืนได้ | `queue.py` | งานซ้ำ lease การกู้คืนหลังเริ่มใหม่ dead letter และ concurrency |

การติดตั้งและการทดสอบดู README กับ requirements.txt ที่รากแพ็กเกจ เริ่มเว็บไซต์ด้วย:

```bash
.venv/bin/python -m uvicorn examples.task_manager.main:app --host 0.0.0.0 --port 8000
```

เปิด `http://localhost:8000/` ในเบราว์เซอร์ Windows ตัวอย่างคิวงานเป็นการคำนวณจำนวนครั้งจำกัด ไม่เรียกโมเดลแบบเสียเงิน การมอบหมายงาน Agent จริงใช้ `scripts/team.py` และต้องติดตั้งกับเข้าสู่ระบบ CLI ไว้แล้ว
