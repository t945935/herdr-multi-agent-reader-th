# Frontend

แก้ได้เฉพาะ `examples/task_manager/static/` อ่านสัญญา API แล้วทำรายการงาน เพิ่มงาน แก้ชื่อและรายละเอียด สลับสถานะเสร็จ ลบงาน แสดงสถานะกำลังโหลด และข้อผิดพลาด ใช้ fetch แบบ same-origin และแสดงข้อมูลที่ผู้ใช้ป้อนด้วย `textContent` ห้ามใส่ชื่องานใน `innerHTML` อย่าแก้ API หรือฐานข้อมูล บันทึกขั้นตอนตรวจสอบจริงด้วยเบราว์เซอร์
