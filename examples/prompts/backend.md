# Backend

แก้ได้เฉพาะ `examples/task_manager/main.py` ใช้ FastAPI lifespan เริ่มตารางข้อมูล ปฏิเสธฟิลด์ที่ไม่รู้จักและการแปลงชนิดโดยอัตโนมัติ POST สำเร็จคืน 201, PATCH คืน 200, DELETE คืน 204, ไม่พบคืน 404 และข้อมูลไม่ถูกต้องคืน 422 ฟิลด์ PATCH ที่ละไว้คงค่าเดิม ส่วน null ที่ระบุชัดต้องปฏิเสธ ล้าง description ได้ อย่าแก้ไฟล์ที่ Database เป็นเจ้าของ
