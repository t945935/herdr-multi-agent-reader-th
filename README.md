# แพ็กเกจตัวอย่างสำหรับผู้อ่านฉบับภาษาไทย

แพ็กเกจนี้ประกอบด้วยโค้ด การทดสอบ และ prompt ตามบทบาทสำหรับหนังสือฉบับภาษาไทย

ฉบับเผยแพร่: [repository](https://github.com/t945935/herdr-multi-agent-reader-th) · [v1.0.0](https://github.com/t945935/herdr-multi-agent-reader-th/releases/tag/v1.0.0) ดาวน์โหลด ZIP และ SHA-256 ได้จาก Assets ของ Release

## ติดตั้งและทดสอบ

ใช้ Python 3.12 และรันทุกคำสั่งจากไดเรกทอรีนี้:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q tests
```

ตัวอย่างคะแนนกำหนดเป็นสัญญาของแบบฝึกหัด: มีสามวิชา คะแนน 0–100 และค่าเฉลี่ยตั้งแต่ 60 เป็น “ผ่าน” ไม่ได้หมายความว่าเป็นระเบียบของทุกโรงเรียนในไทย

## สิทธิ์การใช้งานและการเผยแพร่

Happy eBook เป็นผู้จัดพิมพ์และผู้ถือสิทธิ์การเผยแพร่ฉบับภาษาไทยและแพ็กเกจผู้อ่าน ตามการยืนยันของผู้ใช้เมื่อ 2026-11-09 ไม่มีการให้ใบอนุญาตโอเพนซอร์สทั่วไป เงื่อนไขการใช้งานให้ยึดตามประกาศของผู้ถือสิทธิ์ใน repository นี้
