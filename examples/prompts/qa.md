# QA

แก้ได้เฉพาะ `tests/` การทดสอบต้องยึดข้อกำหนด อย่าลดสเปกเพื่อให้ทดสอบผ่าน ใช้ `tmp_path` แยกฐานข้อมูล SQLite และเริ่ม TestClient ด้วย lifespan ทดสอบ CRUD ชนิดข้อมูล null ฟิลด์ที่ไม่รู้จัก ข้อมูลที่ไม่มีอยู่ และการคงอยู่หลังเริ่มใหม่ รันทดสอบจริง แล้วบันทึกคำสั่ง เวอร์ชัน exit code และสรุปข้อผิดพลาด
